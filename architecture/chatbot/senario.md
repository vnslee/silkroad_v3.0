# 챗봇 시나리오

## 공통 사항
- 답변은 10줄 이내로 너무 길지 않게 제한
- 답변 내용에 핵심적인 내용만 포함
- 기존에 이미 있는 국가의 정보 문의 후 답변 시 국가상세 정보 옵션 표시
  - 만약 보고서도 있는 경우 국가 보고서 팝업 옵션 표시
- 기존에 이미 있는 권역의 정보 문의 후 답변 시 권역상세 정보 옵션 표시
  - 만약 보고서도 있는 경우 권역 보고서 팝업 옵션 표시
 
## 흐름
- 최초 화면 로드 시 사용자에게 선택지 제공
  - Case1: 새로운 국가 추가
     - YES: 리서치 수행 여부 추가 질의 -> YES인 경우 리서치 트리거
     - NO: Case 2 기반 질의 수행
  - Case2: 진출하려는 국가 또는 특정 권역 내 퀵인 가능한 국가 조사
    - 진출하려는 국가 선택 시
      - 비지니스/시스템/Both 어떤 관점으로 설명할지 추가 질의
      - 답변 시 선택한 관점에 따라 답변
    - 특정 권역 내 퀵인 가능한 국가 선택 시
      - 비지니스/시스템/Both 어떤 관점으로 설명할지 추가 질의
      - 답변 시 선택한 관점에 따라 답변
  - Case3: 특정 국가 또는 권역 데이터 기반 사용자 문의 답변
    - 비지니스/시스템/Both 관점 선택이 필요한 경우 사용자에게 질의
